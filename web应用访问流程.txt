整体分 5 大阶段：DNS 解析 → TCP 连接 → HTTP 请求 → 服务器处理 → 浏览器渲染页面。

  例如场景：IDEA 运行 Vue 前端 + SpringBoot 后端 + 数据库（Oracle）

1. 启动服务
在 IDEA 中启动 SpringBoot 后端；启动 Vue 前端开发服务器。
SpringBoot 启动内置 Tomcat，监听端口，等待接收 HTTP 请求；同时建立好和数据库的连接池。
 Vue 前端开发服务器启动，监听前端端口。
2. 用户发起访问
浏览器输入前端项目地址。
3. DNS 解析
浏览器把域名查询转换为服务器 IP 地址。依次查询浏览器缓存、操作系统缓存，缓存无记录则向 DNS 服务器发起查询，最终获取目标服务器 IP。
例如访问`localhost`直接解析为`127.0.0.1`本机 IP。
4. TCP 三次握手
浏览器与前端开发服务器建立 TCP 连接。
5. 浏览器发送 HTTP 请求
向前端服务请求 HTML、CSS、JS 等静态页面资源。
6. 前端服务返回静态资源
前端服务器把页面文件打包，作为 HTTP 响应返回浏览器。
7. 浏览器解析渲染页面
8. 解析 HTML，生成 DOM 树
9. 解析 CSS，生成 CSSOM 树
10. DOM 树与 CSSOM 树合并，生成渲染树
11. Layout（布局）：计算页面元素位置、尺寸
12. Paint（绘制）：渲染页面到屏幕
同时加载并执行 JS 脚本。
13. 用户交互，触发接口请
用户在页面点击按钮、查询数据，前端 JS 发起 Ajax 异步请求，访问 SpringBoot 后端接口。
14. 建立 TCP 连接，向后端发送 HTTP 请求
浏览器和 SpringBoot 服务建立 TCP 连接，发送接口请求报文。
15. SpringBoot 接收请求，访问数据库
16. Controller 接收 HTTP 请求
17. 调用 Service 业务层代码
18. Service 调用 Mapper（MyBatis），向 Oracle 数据库发送 SQL 语句
19. 数据库收到 SQL，执行查询 / 更新操作，把结果集返回给 SpringBoot
20. 后端封装数据返回
SpringBoot 拿到数据库返回的数据，封装为 JSON，通过 HTTP 响应发回浏览器。
21. 前端 JS 接收 JSON，局部更新页面
前端拿到后端返回的数据，修改页面 DOM，刷新对应区域，不用重新加载整个网页。
22. TCP 四次挥手，断开本次 HTTP 连接
本次请求数据传输完毕，断开 TCP 连接。
